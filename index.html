لوحة بث الكروت — BinAref Player

اكتب الكرت، عاينه، ثم انشره إلى Supabase — يصل لكل من يفتح فيديو وهو متصل. غير متصل

الاتصال بـ Supabase

⚠️ مفتاح service_role يمنح صلاحية كاملة على قاعدتك ويتجاوز الحماية. يُحفظ في متصفحك فقط (localStorage) ولا يُرسل لأي مكان سوى Supabase. لا تضعه في أي ملف عام ولا تُدخِله والموقع عام على الإنترنت — استعمل اللوحة محلياً. تجده في: Supabase → Project Settings → API → service_role.

محرّر الكرت

اجعل خلفية الصفحة شفافة ليظهر شكل الكرت فقط. للتحكم بالتطبيق: BinAref.close() لإغلاق الكرت، BinAref.open('https://…') لفتح رابط.
حقول متقدمة (اختيارية)
تُستعمل حقول fallback (نص/زر) فقط لو تعذّر عرض HTML على جهاز قديم.

معاينة حيّة

المعاينة تعرض الكرت بالحجم الفعلي فوق خلفية داكنة تحاكي الفيديو.
